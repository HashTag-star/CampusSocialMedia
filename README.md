# University Social Media Platform (Backend)

## Setup

1.  **Prerequisites**: Node.js, PostgreSQL.
2.  **Install**: `npm install`
3.  **Database**: Create database `campus_social_db`.
4.  **Env**: Check `.env` file.

## Running

-   **Seed Data**: `node src/seeders/seed.js`
-   **Start Dev**: `npm run dev`
